# Sprint-7---Data-Analysis
Creació de funcions, estructures de dades i bucles

En aquest sprint resoldràs diversos problemes reals que podria afrontar un analista de dades, aplicant estructures de dades, funcions i control de flux en Python. L'objectiu no és només escriure codi, sinó demostrar que saps pensar algorísmicament, és a dir:

» Descompondre un problema en parts.
» Definir els passos abans de programar.
» Crear funcions modulars on cada una resol una tasca concreta.
» Expressar clarament el teu raonament.
